# 本机运行方式

本机 `node` 不在 PATH 上，要用 DSH 自带的 Node（v24.21.0，含 `zstdDecompressSync`）：

```
C:\Users\MSN\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe
```

## 常用命令

```powershell
$node = "C:\Users\MSN\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
$ws   = "D:\deepseek-harness\default-workspace"

& $node "$ws\tools\scan-sessions.mjs" list
& $node "$ws\tools\scan-sessions.mjs" calls "ERR|denied|失败|不生效"
& $node "$ws\tools\procedures-probe.mjs" --once --replay
& $node "$ws\tools\procedures-probe.mjs" --keyword "[\\/]procedures[\\/]"
```

会话根自动解析：本机 `DSH_HOME=C:\Users\MSN\.dsh`，脚本读 `C:\Users\MSN\.dsh\sessions`。

## 提醒

- 脚本输出含本机绝对路径与会话原文，贴到公开处前先脱敏。
- 脚本依赖宿主内部日志格式，升级后可能**静默**失效（不报错、只读不到内容）。
